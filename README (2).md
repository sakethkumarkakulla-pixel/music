# SoundWave — Music Streaming Website

Responsive music streaming UI built with HTML, CSS and vanilla JavaScript.

## Sections included
- Artists and artist cards
- Featured albums
- Curated playlists
- Recently played songs
- Popular tracks
- Music-player bar with play/pause, next/previous, shuffle, repeat toggle, progress and volume controls
- Search for tracks
- Responsive desktop and mobile layout

## Run
1. Extract `music-streaming-website.zip`.
2. Open the extracted folder.
3. Double-click `index.html`.

No installation or build tools are required.

## Audio note
This is a front-end demo. Track titles and artist names are sample content. The player demonstrates playback controls and a progress timeline but does not stream audio. Add audio files you own or are licensed to use and connect them to an HTML audio element to enable real playback.
